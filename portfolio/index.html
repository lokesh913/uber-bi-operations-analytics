Data Analysis Findings

Executive Strategic Dashboard Report

Core programmatic findings and analytical splits extracted from the 150,000 records of historical transactional logs.

Cancellation Root-Cause Analysis

The system experiences a **18.0% (27,000)** driver cancellation rate and a **7.0% (10,500)** customer cancellation rate. Out of all customer-side cancellations, Wrong Address Input (2,362) and Change of plans (2,353) are the leading causes.

Driver Cancellation Rate 18.0%

Fleet & Vehicle Performance

Fleets are heavily dominated by Autos (37,419 bookings) and Go Mini Hatchbacks (29,806 bookings), representing **44.8%** of total ride demands. High-end Uber XL SUVs account for **3%** of volume but command higher ticket margins.

Auto & Go Mini Share 44.8%

Payment System Integration

Digital finance adoption is led by **UPI payments (45,909 transactions)** which accounts for **45%** of all generated payments. Cash remains a strong secondary channel at **24.9%**, while debit/credit cards lag behind at under **18.1%**.

UPI Digital Payments Share 45.0%

Actionable Business Recommendations

1

Address Map Address Pin Inaccuracy

Introduce double-confirmation overlays in the rider app to reduce the 2,362 cancellations triggered due to "Wrong Address" inputs.

2

Introduce Fleet Reliability Inspections

Mitigate the 3,012 mid-trip vehicle breakdowns (representing 33.5% of incomplete rides) by launching seasonal maintenance verification programs for driver partners.

3

Targeted Wallet Settlement Cashback

Offer a 5% discount/cashback when riders top-up and use their closed-loop **Uber Wallet** (currently at 12%), reducing transactional fee overheads.

Data Schema Architecture

Data Model & Dimension Mapping

This project uses a clean, relational star schema model built on top of a central Fact table representing transactional bookings linked to Dimension maps.

star_schema_model.sql DAX / SQL 
CREATE TABLE FactBookings (
    Booking_ID VARCHAR(50) PRIMARY KEY,
    Booking_Status VARCHAR(50) FOREIGN KEY,
    Vehicle_Type VARCHAR(50) FOREIGN KEY,
    Pickup_Location VARCHAR(100),
    Drop_Location VARCHAR(100),
    Booking_Value DECIMAL(10,2),
    Ride_Distance DECIMAL(10,2),
    Driver_Ratings DECIMAL(3,2),
    Customer_Rating DECIMAL(3,2),
    Payment_Method VARCHAR(50)
);

-- Linked via active relationships to dimension catalogs
CREATE TABLE DimVehicles (
    Vehicle_Type VARCHAR(50) PRIMARY KEY,
    Img_URL TEXT
);
